Integrating the [Actisense W2K-1 Gateway](https://actisense.com/products/w2k-1-nmea-2000-wifi-gateway/) into the scope gives the project a concrete technical baseline. [1] 
Since the Actisense W2K-1 handles multi-packet assembly natively, you do not need to build complex transport-protocol code. The app can simply read pre-assembled messages straight over the network. [2] 
The updated, comprehensive project description is detailed below:
------------------------------
## Project Description: Sailboat Polar Diagram Creator## 1. Project Overview
The goal of this project is to develop a native Android application that interfaces with a sailboat's NMEA 2000 (N2K) network via an onboard Actisense W2K-1 Wi-Fi Gateway. The app will continuously capture telemetry, save it to a local historical database, and use that information to build a rolling "target speed" performance model. Live performance data will be rendered over a custom 360-degree polar canvas layout. [1, 3, 4] 
------------------------------
## 2. Hardware & Protocol Specification## Hardware Interface

* 
* Device: Actisense W2K-1 Gateway connected to the boat’s NMEA 2000 backbone. [1, 3] 
* Network Protocol: Wi-Fi link configured as either an Access Point (direct connection to 192.168.4.1) or as a Client connected to the boat's local router. [5, 6] 
* Transport Layer: Continuous network stream over TCP or UDP (configurable via the [Actisense Web Interface](https://actisense.com/knowledge-base/nmea-2000/w2k-1-nmea-2000-to-wifi-gateway/nmea-2000-ascii-output-format/) on default data server ports like 60001–60003). [2, 5] 
* 

## Data Protocol & Parsing
The application will be built around the "N2K ASCII" output format configured on the Actisense W2K-1. This format converts N2K messages into human-readable plain text, removing the need for the app to reassemble complex multi-packet or fast-packet strings. [2, 7] 
The app will target and parse the following standard Parameter Group Numbers (PGNs):

* 
* PGN 128259 (Speed, Water Referenced): Extracted for continuous Boat Speed Over Water (SOW).
* PGN 130306 (Wind Data): Extracted for True Wind Speed (TWS) and True Wind Angle (TWA).
* 

------------------------------
## 3. Core Functional Requirements## Data Management (Historical Logging)

* 
* Local Caching: A local database (SQLite/Room) that records filtered SOW, TWS, and TWA entries at a rate of 1Hz (once per second).
* Data Cleansing Filters: To protect historical "target" accuracy, the database will temporarily pause logging or drop points if a sudden, unsustainable spike occurs (e.g., catching a massive wave wave, tacking/jibing, or when an active engine PGN is detected on the network).
* Target Array Construction: Data will be aggregated into discrete matrix blocks based on True Wind Speed (0 to 30 knots) and True Wind Angle (1 to 360 degrees).
* 

## Visualization & UI Layout

* 
* Radial Grid Layout: A 360-degree circular coordinate plot centered around the vessel.
* Angular Axis Intervals: Distinct radial axes rendered at every 30 degrees ($0^{\circ}, 30^{\circ}, 60^{\circ}, 90^{\circ}, 120^{\circ}, 150^{\circ}, 180^{\circ} \dots 360^{\circ}$).
* Concentric Distance Rings: Nested circles defining the wind speed or boat speed scales, explicitly capped from 0 to 30 knots.
* Target Line Overlay: Multi-colored polyline curves overlaying the grid. Each curve represents the maximum historical speed reached in the database for that specific wind velocity tier (e.g., curves for 10kts, 15kts, 20kts wind).
* Live Performance Indicator: A prominent marker mapping the boat's instantaneous TWA, TWS, and SOW on top of the historical curves to show efficiency in real-time.
*

## 4. Technical Stack

| Component [3, 8] | Selected Technology | Reason |
|---|---|---|
| Development Language | Kotlin | Modern, memory-safe, and native Android standard. |
| Networking Architecture | Java Network Sockets / Ktor | Opens an uninterrupted background socket thread to listen to the Actisense Wi-Fi data stream. |
| Local Database Engine | Room Persistence Library | Provides an abstraction layer over SQLite for high-volume data writes. |
| UI Rendering Engine | Jetpack Compose (Canvas API) | Gives pixel-perfect control to draw 30-degree radial grids, responsive polylines, and smooth real-time markers. |

## 5. Development Milestones

[Milestone 1: Actisense Stream] ➔ [Milestone 2: Filtering Engine] ➔ [Milestone 3: 30° Radial Canvas]


   1. Milestone 1: Actisense Connection & Parsing: Implement background services to open a socket connection to the W2K-1, verify data reception, and successfully log raw PGN 128259 and PGN 130306 text lines.
   2. Milestone 2: Database Caching & Max Extraction: Build the schema to record data and design the sorting algorithm that isolates the maximum boat speeds to generate the target curves.
   3. Milestone 3: Polar Visualization: Code the Android graphics UI to draw the 30-degree circular lines, populate the 0-30 knot rings, and plot both the live indicator and target lines simultaneously. [4]
