# Polar

A native Android app that builds a sailboat performance polar diagram from live NMEA 2000 telemetry. It connects to an onboard Actisense W2K-1 Wi-Fi gateway, logs boat speed and wind data over time, derives "target speed" curves from that history, and renders both the targets and a live performance indicator on a 360° polar canvas.
